# Zhiheng Huang (Lowe) — research portfolio website

A responsive, single-page static portfolio for GitHub Pages at `ItsLowe.github.io`. It retains the site's plain HTML/CSS design, research figures and project links. The 12-page MSc Writing Sample includes an added source-introduction page, two original Methodology pages (printed pages 24 and 26), eight original Results pages (printed pages 42–49), and one selected original Bibliography page (printed page 64).

## Selected projects

- **ATP forecasting:** final dissertation results are transcribed to the website and Figure 4.1 is redrawn using the values visible in the final PDF. The reported overall gap reductions are 57.3% and 58.8%; the disagreement-subset reductions are 69.6% and 75.1%. Rounded Table 4.3 values do not reproduce every printed gap percentage exactly. Models were not rerun; source workbooks and match-level records are excluded.
- **Financial security risk monitoring:** the website records the user's described contributions to data collection and cleaning, dataset preparation, model training and hyperparameter selection. It identifies the award as project-level and states that the supplied certificate names Li Biao (李彪), not Zhiheng Huang. It links the Chinese certificate, an unofficial English translation and the bilingual comparison PDF.
- **Bayesian Chess:** **Numerically reproduced with documented discrepancies.** The `post_1996` upper 95% credible interval is 0.353246 versus 0.3431 in the coursework, about 3.16 quantile MCSE. The forecast convention for the Black indicator is unspecified.
- **Hainan Free Trade Port visualisation:** team project using 2019–2023 statistical yearbook data. The supplied deck describes Data Curation and Analysis as the user's role, Vue 3/Vite/ECharts for the interface and an exploratory five-year linear-regression forecast in Python/scikit-learn. No Hainan award or forecast accuracy claim is made. This is a website showcase only; it has no repository link.
- **Dublin green space:** original coursework maps remain with source attribution. Network buffers are accessibility approximations, not validated door-to-park isochrones, and the GIS analysis was not independently reproduced.

The two newer project showcases are part of this portfolio only. No separate GitHub repositories were created for them.
