# Zhiheng Huang — research portfolio website

A responsive, single-page static portfolio published as `ItsLowe.github.io`. It uses the accepted Phase 6 design, plain HTML and CSS, research visuals, and the accepted 12-page MSc Writing Sample. There are no runtime dependencies, analytics or tracking scripts.

## Projects and evidence status

- **ATP forecasting:** reported results and visuals are attributed to the 2026 MSc dissertation and Tennis-Data as the underlying match/odds source. The portfolio figures redraw reported aggregates; the statistical pipeline was not independently rerun for this publication. Source workbooks and match-level records are excluded.
- **Bayesian Chess:** **Numerically reproduced with documented discrepancies.** The `post_1996` upper 95% credible interval is 0.353246 versus 0.3431 in the coursework, about 3.16 quantile MCSE. The original forecast convention for the Black indicator is unspecified; all scenarios and qualifications are in the repository report.
- **Dublin green space:** original coursework maps are shown with source attribution. Network buffers are accessibility approximations, not validated door-to-park isochrones, and the GIS analysis was not independently reproduced.

The author confirms permission for public display of the existing research aggregates, figures, maps and Writing Sample. This release does not redistribute raw ATP match data, lecturer-provided Chess data, private MCMC outputs, original complete coursework reports, or GIS source datasets.

## Website checks

The page has semantic landmarks, labelled navigation, a skip link, visible keyboard focus, descriptive image alternatives, fragment navigation, responsive layouts, a downloadable PDF, and reduced-motion styling. The source site is tested at mobile, tablet and desktop widths; the live Pages deployment should also be rechecked after deployment.
